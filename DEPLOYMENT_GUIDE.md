# BPS Fresh Mills – Production Cloud Deployment Guide

This guide explains how to deploy your existing **BPS** e-commerce store to the cloud so it runs 24/7 on a permanent public **HTTPS** URL (e.g. `https://bps-store.onrender.com` or `https://bps-store.vercel.app`). 

Once deployed, **anyone can access BPS from an Android phone, iPhone, tablet, or laptop from anywhere in the world, and your laptop does NOT need to be turned on**.

---

## 🚀 Recommended Method: 1-Click All-in-One Deployment on Render (Free & Permanent)

Render hosts both your frontend React app and Express backend together on a single permanent HTTPS domain with zero configuration issues.

### Step 1: Push Your Code to GitHub

1. Open a terminal in this project directory (`c:\Users\Dell\Downloads\BPS chakki`).
2. Initialize and commit (if not already done):
   ```bash
   git init
   git add .
   git commit -m "Prepare BPS for production cloud deployment"
   ```
3. Create a new repository on [GitHub](https://github.com/new) named `bps-chakki`.
4. Link and push your repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/bps-chakki.git
   git branch -M main
   git push -u origin main
   ```

### Step 2: Deploy on Render

1. Go to [Render Dashboard](https://dashboard.render.com/) (Sign up for free with GitHub).
2. Click **New +** → **Web Service**.
3. Connect your `bps-chakki` GitHub repository.
4. Fill in these settings:
   - **Name**: `bps-fresh-mills` (or any name you prefer)
   - **Environment**: `Node`
   - **Region**: Choose closest to you (e.g., `Singapore` or `Frankfurt`)
   - **Branch**: `main`
   - **Build Command**: `npm run build`
   - **Start Command**: `npm start`
   - **Plan**: `Free`
5. Under **Environment Variables**, add:
   | Key | Value | Description |
   | :--- | :--- | :--- |
   | `NODE_ENV` | `production` | Enables production mode |
   | `JWT_SECRET` | `bps_super_secure_production_secret_2026` | Any secure random string |
   | `ADMIN_EMAIL` | `bpsfreshmill@gmail.com` | Administrator login email |
   | `ADMIN_INITIAL_PASSWORD` | `bps@2005` | Administrator login password |
   | `FRONTEND_URL` | *Leave empty or set to your Render URL* | Auto-detected on Render |
6. *(Optional: Real Notifications)*
   If you wish to activate real WhatsApp & Email notifications, also add:
   | Key | Value |
   | :--- | :--- |
   | `WHATSAPP_PHONE_NUMBER_ID` | Your Meta WhatsApp Phone Number ID |
   | `WHATSAPP_ACCESS_TOKEN` | Your Meta WhatsApp System User Access Token |
   | `SMTP_HOST` | e.g. `smtp.gmail.com` or SendGrid |
   | `SMTP_PORT` | `587` |
   | `SMTP_USER` | Your email address |
   | `SMTP_PASS` | Your email app password |
7. Click **Create Web Service**.

Render will install dependencies, build the frontend (`dist`), and start the Express server.
Within 2 minutes, your website will be live at:
👉 **`https://bps-fresh-mills.onrender.com`**

## ⚡ Alternative Method: Vercel (Frontend) + Render (Backend)

If you prefer hosting the React frontend on Vercel's global edge network:

### 1. Deploy Backend on Render:
- In Render, create a Web Service pointing to your repo.
- **Root Directory**: `backend`
- **Build Command**: `npm install`
- **Start Command**: `node server.js`
- Set environment variables (`ADMIN_EMAIL`, `ADMIN_INITIAL_PASSWORD`, `JWT_SECRET`).
- Note your backend URL: e.g. `https://bps-api.onrender.com`.

### 2. Deploy Frontend on Vercel:
- Go to [Vercel Dashboard](https://vercel.com/) and click **Add New** → **Project**.
- Import your `bps-chakki` repository.
- **Root Directory**: Select `frontend`.
- **Framework Preset**: `Vite`
- Under **Environment Variables**, add:
  - `VITE_API_BASE`: `https://bps-api.onrender.com/api`
- Click **Deploy**.
- Your frontend will be live on Vercel at `https://bps-store.vercel.app`!
